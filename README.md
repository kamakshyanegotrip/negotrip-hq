# NegoTrip HQ

A launcher for all NegoTrip tools. You create your own categories (Research, Sales & Marketing, and so on) and add a tile for each tool you use. It works on a computer and installs on a phone like an app.

**Live page:** https://kamakshyanegotrip.github.io/negotrip-hq/

## Install on your phone

- **Android (Chrome):** open the live page, tap ⋮ → **Install app** or **Add to Home screen**.
- **iPhone (Safari):** open the live page, tap Share → **Add to Home Screen**.

## Where your tools are saved

Categories, tools and pins are saved in the browser of the device you add them on. They are not uploaded anywhere.

To move them to another device, open **Backup & move to another device** at the bottom of the page:

1. Tap **Export** on the device that has your tools, then save the file or copy the text.
2. On the other device, tap **Import** and pick the file or paste the text.

Clearing your browser data removes the list, so export a backup now and then.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole app |
| `manifest.webmanifest` | Name, colours and icons for installing on a phone |
| `sw.js` | Lets the app open without internet |
| `icon.svg`, `icon-192.png`, `icon-512.png` | App icons |
